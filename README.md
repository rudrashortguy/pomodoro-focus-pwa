# FocusFlow PWA

Minimalist Pomodoro timer with ambient background sounds and task statistics.

### Features
- Customizable timers
- Audio synthesizer sounds
- Offline session logging
- Dark mode support

### Tech Stack
- **Vite** & **TypeScript**
- **Workbox / Vite PWA Plugin** for offline capabilities
- **IndexedDB & LocalStorage** for persistent state

### Getting Started
```bash
npm install
npm run dev
```
